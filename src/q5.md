# Question 5 — Operating Systems, Terminals, and Shells

**Format:** Short Answer

---

> Answer in your own words, 1-3 sentences each. Writing it yourself is the point.


**(a)** What is a **kernel**, in plain language? (One or two sentences. No textbook definition copied in; explain it as you understand it.)

**Answer:**
_(The kernel is a set of operating system files are loaded on bootup that control the computer hardware such processor, memory, devices such as keyboard, display, network adapter, hard disk and others by making calls to Basic Input and Output System. Each type OS has its own unique kernel whereas the BIOS is only dependent of the motherboard and is the same for all OS.)_

---

**(b)** A classmate says:

> "I installed WSL, so now I have two completely separate operating systems, Windows and Linux, running side by side, each totally independent."

Is this accurate? Briefly explain why or why not.

**Answer:**
_(This is not accurate. WSL and Windows are running in parallel independently using Microsoft Hyper-V Type 1 Hypervisor technology sharing the same processor and hardware such as file system, keyboard and display. However that allocation of these hardware dynamically control to allocate for more optimize and efficient use of these resources.)_

---

**(c)** Explain the difference between a **terminal (emulator)** and a **shell**, and give one example of each.

**Answer:**
_(A terminal (emulator) is an application to simulate the virtual operation of an OS. It cannot control the actual hardware of the computer. An example is QEMU.

A shell is a real interpret that provide interface for the user to interact with the OS. An example is bash shell.
)_
